# Multimodal Attendance System

An end-to-end multimodal attendance tracking system built for modern university environments. It supports tracking student attendance via physical NFC cards (using an ESP32 edge node) and dynamically generated cryptographic QR codes (via a mobile app). 

## Architecture

The system consists of 4 main components:
1. **ESP32 Firmware (`/firmware`)**: Runs on an ESP32 connected to a PN532 NFC reader. It polls Supabase Edge Functions for the active session and processes NFC taps locally before sending them to the backend. It also exposes a Web Serial configuration interface.
2. **Web Dashboard (`/dashboard`)**: A Next.js (App Router) web application for lecturers and administrators to manage courses, enroll students, and launch live attendance sessions.
3. **Mobile App (`/mobile`)**: A Flutter cross-platform mobile application for students to scan QR codes generated by the dashboard during an active session, as well as view their real-time attendance trends.
4. **Supabase Backend (`/supabase`)**: The Postgres database, Edge Functions (Deno), and Row Level Security (RLS) policies acting as the central nervous system.

## Getting Started

### 1. Supabase Backend Setup
1. Create a new [Supabase](https://supabase.com) project.
2. Link your local project: `npx supabase link --project-ref your-project-ref`
3. Push the database migrations: `npx supabase db push`
4. Deploy the Edge Functions: `npx supabase functions deploy`
5. Configure your environment variables in Supabase (Dashboard -> Project Settings -> Edge Functions):
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `QR_SECRET_KEY` (See QR Secret Rotation below)

### 2. Dashboard Setup
1. Navigate to the `/dashboard` directory.
2. Copy `.env.example` to `.env.local` and fill in your `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
3. Install dependencies: `npm install`
4. Run the development server: `npm run dev`

### 3. Firmware Flashing
1. Open `/firmware/attendance_node/attendance_node.ino` in the Arduino IDE.
2. Install the necessary libraries (`WiFi`, `HTTPClient`, `ArduinoJson`, `Adafruit_PN532`, `WebSocketsServer`).
3. Connect your ESP32 board and compile/upload the sketch.
4. Once flashed, connect the ESP32 to your PC via USB and use the Dashboard's **Device Setup** page (Web Serial API) to securely transmit Wi-Fi credentials and sync the time.

### 4. Mobile App Setup
1. Navigate to the `/mobile` directory.
2. Install dependencies: `flutter pub get`
3. Run the app: `flutter run`

## Operations & Security

### QR Secret Rotation (`QR_SECRET_KEY`)
The QR codes generated by the dashboard for students to scan are cryptographically signed using an HMAC-SHA256 hash to prevent spoofing and forgery. The secret used to generate these signatures is stored in the `QR_SECRET_KEY` environment variable on Supabase Edge Functions.

**To rotate the secret (e.g. if compromised):**
1. Generate a new secure random string.
2. Update the Edge Function secrets:
   ```bash
   npx supabase secrets set QR_SECRET_KEY=your-new-secure-secret-here
   ```
3. Restart the edge functions if required. All previously generated QR codes will instantly become invalid.

### ESP32 Enrolment Security
Physical NFC cards are bound to students via the Dashboard. When a lecturer clicks "Activate Enrolment Mode", the ESP32 briefly switches from "Attendance" to "Enrolment" mode. The PN532 reads the card UID, normalises it to a 4 or 7-byte uppercase hex string, and binds it to the student.
